# Quarry

Find the right founders to cold email — automatically.

Drop in your resume PDF. Get back 10 relevant founder profiles, one non-obvious insight about each, and a personalized cold email draft.

## What it does
1. Parses your resume and extracts your skills, projects, and domains
2. Searches for founders building in spaces relevant to you
3. Generates a profile + cold email for each founder

## Stack
- Python
- Groq (LLaMA 3) — fast, free LLM
- Tavily — web search
- pdfplumber — resume parsing

## Usage
```bash
python main.py resume.pdf
```
